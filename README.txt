DAYFLOW — iPhone-first Personal Planner prototype

Included:
- Responsive iPhone-friendly planner interface
- Example daily timeline across home, family, personal, work, meetings and learning
- Mark tasks complete; progress updates
- Filter tasks by category
- Add a task with duration, priority and deadline; suggest a slot around fixed commitments
- Local browser storage for tasks and daily intention
- PWA manifest and service worker for installable hosting

Important:
This is a functional front-end prototype, not a published App Store app. The slot finder is a simple local heuristic, not an AI service, and the example schedule must be adjusted to your real commitments. Tasks are stored on the device/browser. Calendar sync, notifications, cloud backup, reliable conflict optimization, and native iOS packaging are not yet implemented.

To test:
Open index.html in a browser. For PWA installation on iPhone, host this folder on an HTTPS website, open the URL in Safari, tap Share, then Add to Home Screen. Service workers and installability generally require HTTPS hosting.
